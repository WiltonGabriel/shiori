# Shiori (栞)

API REST para gerenciamento de catálogo pessoal e rastreamento de ciclos de leitura.

## Tecnologias

- **Java 25**
- **Spring Boot** (Web, Data JPA, Validation)
- **PostgreSQL**
- **Maven**

## Execução

1. Configure as credenciais do PostgreSQL em `src/main/resources/application.properties`.
2. Execute a aplicação utilizando o Maven Wrapper:

```bash
./mvnw spring-boot:run
```
